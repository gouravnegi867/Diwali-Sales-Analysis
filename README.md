# Diwali Sales Analysis

## Project Overview
This project focuses on data cleaning and exploratory data analysis (EDA) using Python on Diwali sales data.

## Libraries Used
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Tasks Performed
- Data Cleaning
- Handling Missing Values
- Exploratory Data Analysis
- Data Visualization

## Key Insights
- Married women aged 26–35 purchased more products
- Uttar Pradesh and Maharashtra showed higher sales
- IT sector customers spent more during Diwali

## Conclusion
The analysis helped identify customer purchasing behavior and sales trends during the Diwali festival season.
